# Push Button Counter Using Arduino and LCD

## Project Overview
The Push Button Counter is an Arduino-based electronics project that counts button presses and displays the count on an LCD. It demonstrates basic digital input handling, counter logic, and LCD interfacing.

## Objectives
- Count push button presses.
- Display the counter value on an LCD.
- Understand Arduino programming and hardware interfacing.
- Demonstrate the interaction between input devices and output displays.

## Components Used
- Arduino board
- Push button
- LCD display
- Connecting wires
- Breadboard, if used
- USB cable or suitable power supply

## Working Principle
1. The Arduino initializes the LCD and counter.
2. The push button acts as the input.
3. When a valid button press is detected, the counter value is updated.
4. The updated count is displayed on the LCD.
